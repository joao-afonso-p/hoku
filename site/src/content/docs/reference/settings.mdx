Open **Settings** from the bottom of the rail. Changes apply immediately.

## Galaxy visibility

| Setting | Default | Effect |
|---|---|---|
| **Recent window** | 7 days | What counts as recent on the Current map: 3, 7, 14 or 30 days |
| **Always show live sessions (working, ready, open)** | On | Live sessions stay on the Current map however old their last activity |
| **Always show favorites** | On | Favorites stay on the Current map however old |
| **Hide inactive projects** | Off | Projects with nothing current leave the Current map. The others don't move. |
| **Galaxy ambience** | Subtle motion | **Subtle motion** lets the background drift and follow the cursor a little. **Still** stops it. Runtime animations stay on in both, and macOS *Reduce motion* turns motion off. |

Sessions that need you are always on the map, whatever these settings say. [Search](/hoku/guides/search/) always covers everything. See [The Galaxy](/hoku/guides/galaxy/).

## Needs You alerts

| Setting | Default |
|---|---|
| **Notify me when a session needs me** | Off |
| **Show the Needs You count on the Dock icon** | On |
| **Bounce the Dock icon once** | Off |

If macOS permission is missing, or Hoku's alerts or badges are turned off in System Settings, a note appears here with **Open System Settings**. See [Alerts and the Dock](/hoku/guides/needs-you/#alerts-and-the-dock).

## Claude Code opens in

On macOS: **Automatic** (iTerm if it's installed, otherwise Terminal), **iTerm** or **Terminal**. This is where **Go to terminal** opens a new tab or window when a session isn't already running. A session that's already open in a terminal is always brought forward where it is.

On Linux the same setting lists the terminal emulators that are installed. Automatic picks the first of those. A new session opens in a window, not a selected tab. See [Getting back to a session](/hoku/guides/opening-sessions/).

Dock badge and Dock bounce are macOS-only. On Linux, Needs You alerts are desktop notifications via `notify-send` when that command is installed.

## AI drafts · optional

**Let Claude draft project descriptions in Resume**: off by default. Below it, Hoku shows whether the Claude Code CLI is installed, new enough and signed in. Turning it on lists what a draft sends before you confirm. See [AI drafts](/hoku/guides/resume/#ai-drafts-optional).

## Demo data

**Load demo** adds three labeled demo projects with sessions in every state. **Remove demo data** deletes them, with anything tied to them.
