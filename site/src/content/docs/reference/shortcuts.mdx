title: Keyboard shortcuts
description: Every keyboard shortcut in Hoku, on the map, in lists, in the command palette and in editors.
---

## Anywhere

| Keys | Action |
|---|---|
| <kbd>⌘</kbd><kbd>K</kbd> | Open or close [search](/hoku/guides/search/) |
| <kbd>⌘</kbd><kbd>N</kbd> | [Add a session](/hoku/guides/adding-sessions/) (into the focused project) |
| <kbd>⌘</kbd><kbd>⇧</kbd><kbd>S</kbd> | Scan for sessions |
| <kbd>⌘</kbd><kbd>⇧</kbd><kbd>A</kbd> | Switch the Galaxy between Current and All |
| <kbd>⌘</kbd><kbd>0</kbd> | Back to the Galaxy |
| <kbd>⌘</kbd><kbd>1</kbd> … <kbd>⌘</kbd><kbd>9</kbd> | Zoom into project 1 to 9 |
| <kbd>Esc</kbd> | Back out one level: a sheet, then the selected session, then a drawer, then Sessions or Recaps, then the project, then a status filter |

## With a session selected

| Keys | Action |
|---|---|
| <kbd>↵</kbd> | Open it in its app (**Go to terminal** for Claude Code) |
| <kbd>F</kbd> | Add it to [Follow up](/hoku/guides/follow-up/), or mark it done |
| <kbd>⌘</kbd><kbd>C</kbd> | Copy its ID (when no text is selected) |

## In a project

| Keys | Action |
|---|---|
| <kbd>Tab</kbd> / <kbd>⇧</kbd><kbd>Tab</kbd> | Next or previous session, most recent first |
| <kbd>R</kbd> | Open or close the project's [Resume](/hoku/guides/resume/) |

## In search (⌘K)

| Keys | Action |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd>, or <kbd>Ctrl</kbd><kbd>P</kbd> <kbd>Ctrl</kbd><kbd>N</kbd> | Move through results |
| <kbd>↵</kbd> | Open the session, enter the project, or run the action |
| <kbd>⌘</kbd><kbd>↵</kbd> | Show the session on the map |
| <kbd>⌥</kbd><kbd>↵</kbd> | Filter the Galaxy to the session's state |
| <kbd>⌘</kbd><kbd>P</kbd> | Go to the session's project |
| <kbd>⌘</kbd><kbd>D</kbd> | Favorite or unfavorite |
| <kbd>⌘</kbd><kbd>F</kbd> | Follow up, or mark done |
| <kbd>⌘</kbd><kbd>C</kbd> | Copy the session's ID |
| <kbd>Esc</kbd> | Close |

## While editing

| Where | Keys |
|---|---|
| A session's title in the inspector | <kbd>↵</kbd> saves, <kbd>Esc</kbd> cancels |
| About and Next step in Resume | <kbd>⌘</kbd><kbd>↵</kbd> saves, <kbd>Esc</kbd> cancels |
| The Forget confirmation | <kbd>Esc</kbd> cancels |

In Recaps, <kbd>Tab</kbd> and <kbd>↵</kbd> move through and press its controls, as in any form.

## On the map

| Do | To |
|---|---|
| Click / double-click a session | Inspect it / open it |
| Drag a session onto a project | Move it there |
| Drag the background, or scroll | Pan |
| Pinch, or <kbd>⌘</kbd> + scroll | Zoom |
